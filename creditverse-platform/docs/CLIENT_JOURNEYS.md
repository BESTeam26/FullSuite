# BES Client Journeys

> One client keeps one identity and history across the ecosystem.

## Journey A — Consumer starts DIY

```
DIY Credit
  → Needs Professional Help
  → CreditOps / Done For You
  → Becomes Funding Ready
  → FundingOps
  → Funding Opportunity
```

A customer can start with a lower-cost self-service solution. If they need
professional assistance, the company moves them into its managed CreditOps
service. When appropriate, the same customer can later enter a funding
workflow. Their history does not need to start over.

## Journey B — Funding company

```
Funding Application
  → Funding Readiness Review
  → Credit/Readiness Barrier Identified
  → Choose Path
     ├─ DIY Credit
     └─ Professional Credit Service / CreditOps
  → Credit/Readiness Work
  → Reassessment
  → Return to FundingOps
  → Potential Lender Programs
  → Submission → Offer → Funding
```

**Do NOT say:** "Rejected → Fix Credit → Guaranteed Funding."

The funding-readiness review may identify credit or other readiness factors
requiring attention. Credit improvement does not guarantee funding approval.

## Journey C — Credit repair company

```
Credit Client
  → CreditOps
  → Progress
  → Funding Interest Identified
  → FundingOps
  → Funding Application → Readiness → Submission
```

A credit company can add funding operations later without replacing CreditOps
or creating another disconnected client database.

## Journey D — Funding-only company

FundingOps works independently. The company does NOT need CreditOps. If the
company already has another credit-repair solution, FundingOps remains fully
functional.

## Journey E — Credit-only company

CreditOps works independently. The company does NOT need FundingOps.

## Conversion states

```
Suggested → Offered → Requested → Accepted → Declined → Completed
```

A conversion is counted **only when service enrollment actually changes**.

## Conversion types

- DIY → Managed Credit
- DIY → Funding Readiness
- DIY → FundingOps
- Managed Credit → FundingOps
- FundingOps → DIY
- FundingOps → Managed Credit

## Shared vs professional-only data

**Shared (Client 360):**
- Client identity
- Reports
- Documents
- Evidence
- Activity
- Progress

**Professional-only (CreditOps):**
- QA
- Processor assignments
- Dispute routing
- Compliance workflow
- Mailing operations
- Production
- Time tracking
- Internal notes
